# LoveLetter — Интерактивные романтические приглашения

SaaS-платформа для создания красивых интерактивных приглашений с фотографиями, музыкой, анимациями и личными посланиями.

## 🚀 Возможности

### Для создателей
- **6 готовых шаблонов** для разных поводов (свидание, годовщина, предложение, день рождения, валентинка, сюрприз)
- **Визуальный редактор** с предпросмотром в реальном времени
- **11 типов сцен**: обложка, письмо, галерея, конверт, вопрос, выбор, таймер, аудио, секрет, финал, свободная
- **12 типов элементов**: заголовки, текст, печатная машинка, изображения, кнопки, конверты, секретные карточки, вопросы, сердечки и другие
- **Анимации**: плавное появление, масштабирование, печатание текста, летающие сердечки
- **Адаптивный редактор** для мобильных и десктопных устройств
- **Публикация по уникальной ссылке** — получатель открывает без регистрации

### Для получателей
- Красивая анимированная история на смартфоне
- Интерактивные элементы: конверты, вопросы, выбор вариантов
- Секретные послания и анимации
- Подтверждение участия с сохранением ответа
- Конфетти-эффект на финальном экране

## 🛠 Технологический стек

- **React 18** + **TypeScript**
- **Vite** для сборки
- **Tailwind CSS 4** для стилей
- **Framer Motion** для анимаций
- **React Router** для навигации
- **Lucide React** для иконок
- **pako** для сжатия данных
- **localStorage** для хранения проектов (в MVP-версии)

## ✅ Как работают ссылки

**Приглашения работают между любыми браузерами и устройствами!**

Данные приглашения сжимаются и кодируются прямо в URL, поэтому:
- ✅ Ссылка работает в любом браузере
- ✅ Ссылка работает на любом устройстве (телефон, планшет, компьютер)
- ✅ Можно отправлять ссылку кому угодно через мессенджер, email, SMS
- ✅ Не требуется сервер или база данных
- ✅ Полностью автономно

**Технические детали:**
- Данные сжимаются с помощью pako (zlib deflate)
- Затем кодируются в base64 URL-safe формат
- Сжатие уменьшает размер ссылки в 3-5 раз
- При повторной публикации ссылка обновляется с новыми данными
- Максимальный размер проекта: ~500KB (после сжатия)

**Исправленные проблемы:**
- ✅ Исправлена ошибка при кодировании больших проектов
- ✅ Добавлена обработка ошибок с понятными сообщениями
- ✅ Улучшена работа с большими массивами данных

### Как протестировать

1. Запустите `npm run dev`
2. Создайте приглашение из шаблона
3. Отредактируйте и опубликуйте его
4. Скопируйте ссылку
5. Откройте её в **любом браузере** на **любом устройстве**
6. Вы увидите интерактивное приглашение

### Для production-версии (опционально)

Для большей надёжности и дополнительных возможностей можно подключить **Supabase** (PostgreSQL + Auth + Storage). См. раздел [Roadmap](#-roadmap-production-версия).
